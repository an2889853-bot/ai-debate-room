# 설치 가이드 — 처음 받는 분용

이 문서만 따라 하면 됩니다. git·GitHub 계정·프로그래밍 지식은 필요 없습니다. **Windows 10/11** 기준이고, 걸리는 시간은 10~15분(대부분 다운로드 대기)입니다.

## 시작 전에 확인 — 이 둘이 있어야 합니다

| 필요한 것 | 왜 | 없으면 |
|---|---|---|
| **Claude 구독** (Pro 이상) | 토론의 한쪽(Claude)이 이 계정으로 답합니다 | Claude 쪽을 못 씀 |
| **ChatGPT 구독** (Plus 이상) | 다른 한쪽(GPT)이 이 계정으로 답합니다 | GPT 쪽을 못 씀 |

앱은 두 회사의 **공식 명령줄 프로그램(CLI)**을 여러분 PC에 설치해 여러분 계정으로 부릅니다. 만든 사람의 계정을 쓰는 게 아니고, 별도 API 요금도 없습니다. 단, 토론 한 번에 CLI 호출이 4~8회 들어가니 구독 사용량 한도가 있는 요금제라면 참고하세요.

## 1단계 — 코드 받기 (1분)

1. 브라우저에서 **https://github.com/an2889853-bot/ai-debate-room** 을 엽니다
2. 초록색 **Code** 버튼 → **Download ZIP**
3. 다운로드된 `ai-debate-room-main.zip`을 **압축 풀기** (오른쪽 클릭 → 압축 풀기)
4. 풀린 폴더를 원하는 곳으로 옮깁니다. 추천: `C:\Users\<내 이름>\ai-debate-room` (폴더 이름은 마음대로, 한글·공백 없는 경로가 안전합니다)

## 2단계 — 설치 (5~10분, 대부분 자동)

1. 폴더 안 **`setup.cmd`** 를 더블클릭
   - "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보 → 실행** (인터넷에서 받은 스크립트라 뜨는 표준 경고입니다)
2. 검은 창에서 `=== 1/6 … ===` 순서로 진행됩니다. 자동으로 하는 일:
   - uv(파이썬 설치 도구) → 파이썬 3.14 → 앱 패키지
   - Claude Code CLI 설치 → **브라우저 로그인 창** (Claude 구독 계정으로 로그인 → Authorize)
   - Codex CLI 설치 → **브라우저 로그인 창** (ChatGPT 구독 계정으로 로그인)
   - 마지막에 두 CLI 점검
3. 끝에 **"설치 끝"** 초록 글씨와 `✅ claude`, `✅ codex` 두 줄이 보이면 성공. **Enter**로 창을 닫습니다.

> 창 중간에 검은 바탕의 영어 안내문이 지나가는 건 정상입니다. 판단은 마지막 `[문제]` 줄 유무와 `✅` 두 줄로 하면 됩니다.

## 3단계 — 실행

1. 폴더 안 **`launch_ui.cmd`** 더블클릭
2. 검은 창(서버)이 최소화되어 뜨고, 2~3초 뒤 브라우저가 **자동으로** `http://localhost:8501` 을 엽니다. 안 열리면 아무 브라우저 주소창에 `localhost:8501`
3. 아래 입력창에 질문을 쓰면 토론이 시작됩니다. 결과는 폴더 안 `chats\`에 자동 저장됩니다.

자주 쓸 거면 `launch_ui.cmd` 오른쪽 클릭 → **보내기 → 바탕화면에 바로 가기 만들기**.

## 사용 팁

- **모드** (사이드바): 일반 / 코드 리뷰 / PLC 검증 / 투자 분석
- **단계 수**: 3단계(최초 → 검토 → 최종, 기본) 또는 5단계(반박·재검사 추가)
- **웹 검색·파일 실행**은 기본 꺼짐. 사이드바 "🛠 도구"에서 켤 수 있는데, **파일·명령 허용은 AI가 쓴 코드가 이 PC에서 실제로 실행되는 기능**이니 무엇인지 알고 켜세요.
- 진행 중 ⏸로 멈춰 한마디 끼워넣거나 ⏹로 중단할 수 있습니다.

## 막힐 때

| 증상 | 대처 |
|---|---|
| `setup.cmd`를 눌러도 창이 바로 사라짐 | 폴더 경로에 특수문자가 있는지 확인. PowerShell을 열어 `cd 폴더경로` 후 `.\setup.cmd`로 실행하면 메시지가 남습니다 |
| "winget이 없습니다" | Microsoft Store에서 **앱 설치 관리자**를 설치(https://aka.ms/getwinget) 후 다시 `setup.cmd` |
| uv/Claude/Codex "설치를 확인하지 못했습니다" | 새로 설치한 프로그램이 이 창에 아직 안 잡힌 것. 창을 닫고 `setup.cmd`를 **한 번 더** 실행(된 단계는 건너뜀) |
| 로그인 창이 안 뜸 | 브라우저 팝업 차단 확인. 검은 창에 표시된 주소를 복사해 브라우저에 붙여넣어도 됩니다 |
| 점검에서 `❌ codex … 401` | Codex 로그인이 안 된 것 → `setup.cmd` 다시 실행하면 로그인 창만 다시 뜹니다 |
| 브라우저에 "연결할 수 없음" | 서버 검은 창이 닫혔거나 아직 시작 중. `launch_ui.cmd`를 다시 실행 |
| 앱을 완전히 끄고 싶음 | 최소화된 검은 창(서버)을 닫으면 됩니다 |

그래도 안 되면 검은 창 내용을 캡처해서 보내주세요.

## 업데이트

새 버전이 나오면 같은 링크에서 ZIP을 다시 받아 폴더를 덮어쓰면 됩니다. `chats\`(내 대화 기록)와 `ui_settings.json`(내 설정)은 ZIP에 없으니 그대로 남습니다.
